# Agile User Stories
US-01: As a Credit Operations Analyst, I want to identify customers with consecutive missed payments so I can prioritise accounts for review.
Acceptance: 2+ missed payments create an alert with customer, loan and risk information.

US-02: As an Operations Analyst, I want to identify unusual recent debit activity so abnormal behaviour can be investigated.
Acceptance: activity above threshold creates an alert.

US-03: As a Financial Crime Operations Analyst, I want to identify rapid international activity so unusual patterns can be reviewed.
Acceptance: 5+ international transactions across 3+ countries create an alert.

US-04: As an Operations Manager, I want alerts in an escalation queue so cases can be tracked.
Acceptance: every alert links to an escalation with timestamps and status.

US-05: As a Banking Executive, I want a risk/system-health dashboard so I can monitor exposure and workflow performance.
Acceptance: risk alerts, loan exposure, open escalations and resolution time are visible/filterable.

US-06: As a Banking Executive, I want to simulate an interest-rate change so I can understand potential repayment impacts.
Acceptance: selecting a rate adjustment updates scenario rate, repayment and monthly increase.
